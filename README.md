# Лабораторная работа №2 (OWASP Top 10)

Учебный проект, демонстрирующий реализацию уязвимостей, их эксплуатацию и исправление.

## Описание уязвимостей
В приложении `server.py` намеренно реализованы две уязвимости из списка OWASP Top 10:
1. **SQL Injection** (в функции `authenticate`) — возможность обхода авторизации.
2. **IDOR** (в функции `get_note`) — доступ к заметкам другого пользователя по их ID.

## Структура проекта
* `server.py` — уязвимое веб-приложение (запускается на `http://127.0.0.1:8000`).
* `exploit.py` — Python-скрипт для демонстрации (эксплуатации) обеих уязвимостей.
* `patch.diff` — файл с патчем, который закрывает обе уязвимости.

## Как проверить
1. Запустить сервер: `python server.py`
2. В другом окне терминала запустить эксплойт: `python exploit.py`
3. Убедиться, что обе уязвимости успешно эксплуатируются.
